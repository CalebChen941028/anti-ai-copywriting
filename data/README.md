# Empirical End-to-End Preference Alignment Dataset (mimo-v2.6-flash)

[English](README.md) | [简体中文](README.zh-CN.md)

This directory contains real empirical preference pairs extracted from the **mimo-v2.6-flash end-to-end dual-blind benchmark** (`tests/fixtures_mimo/`), designed for Direct Preference Optimization (DPO), SimPO, and fine-tuning LLMs to eliminate AI tropes, translationese, and factual hallucinations. All data is grounded in 100% genuine live HTTP network requests (OpenCode Go gateway, HTTP 200, verifiable audit log), with zero simulated or mock text.

## 2. Provenance & Protocol

- **Evaluation Date**: 2026-10-24
- **Base Model**: `mimo-v2.6-flash` (OpenCode Go gateway endpoint: `https://opencode.ai/zen/go/v1/chat/completions`)
- **Audit Verification**: 24 live HTTP POST requests (all returning 200 OK, mean latency 14,391 ms, consuming 27,976 tokens), with every pair backed by server `response_id`.
- **Dual-Blind Protocol**:
  - `rejected`: Native output generated by bare `mimo-v2.6-flash` without system rules or tools.
  - `chosen`: Output generated with `anti-ai-copywriting` skill prior rules, vetted and remediated by the `anti-ai-lint` deterministic gate.
- **Subjects**: 8 core scenarios spanning academic writing, business memos, grant proposals, popular science, social tech reviews, and information-conservative polish/translate tasks.
- **Empirical Honesty**: Preserves real counter-examples (e.g. flat margins on polish/translate) without synthetic curation.
