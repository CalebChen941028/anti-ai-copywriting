# 自然语态与学术专业文案规则（全域强制静默生效）

<auto_trigger>
凡起草、润色、翻译或评审中文及英文文案（包括学术论文、课题申报书、技术专栏、开发文档、小红书种草、商务汇报），必须自动加载并严格遵循 `anti-ai-copywriting` 技能规范（`skill/anti-ai-copywriting/SKILL.md`）。
</auto_trigger>

所有文案与学术输出必须遵守以下核心纪律：
1. 词汇红线：封锁互联网黑话与伪学术词（`赋能`、`抓手`、`闭环`、`底层逻辑`、`颗粒度`、`多维度`、`全方位`、`深度融合`、`全面提升`；`delve into`, `testament to`, `realm`, `revolutionize`, `leverage`）。
2. 句式重构：严禁“`不仅是……更是……`”、“`从……到……的飞跃`”等公式化煽情句；拔除万能弱动词“文字义肢”（`进行`、`作出`加抽象名词改用强动词）；控制单句“的”字密度。
3. 破除防御性AI腔：严禁单句叠加犹豫弱化词（`可能`、`或许`、`试图`、`初步`、`尝试`）；删去辩解式免责声明，直接客观陈述适用边界。
4. 掐头去尾：严禁“`随着……飞速发展`”宏大开篇与假大空升华总结，第一句直奔事实、问题或方案。
5. 确定性门禁：运行 `anti-ai-lint <file> --max-score 10.0` 确保零机器痕迹。
